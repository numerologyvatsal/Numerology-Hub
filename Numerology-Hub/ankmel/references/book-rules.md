# AnkMel Numerology Rules

## Single Source

Book: Numerology: With Tantra, Ayurveda, and Astrology  
Author: Harish Johari  
Method: Indian / Vedic Numerology

## Allowed Rules

- Psychic Number
- Destiny Number
- Name Number
- Number and ruling planet relationships
- Marriage and relationship rules stated in the book
- Timing rules stated in the book

## Not Allowed

- Lo Shu Grid
- Pythagorean Numerology
- Other Chaldean systems
- Attitude Number
- Master Numbers
- Karmic Debt Numbers
- Custom percentages
- Custom numerology predictions
